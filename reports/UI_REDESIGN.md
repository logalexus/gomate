# Полный редизайн gomate

Переработаны общая оболочка и навигация, список сессий и содержимое пакетов, декодер, настройки, менеджер/редактор шаблонов, поиск в прошлом, добавление/редактирование сервисов, контейнеры/логи, аномалии и чат с Markdown. Новый сценарий работы: [UI_GUIDE.md](../docs/UI_GUIDE.md).

Применены [ui-ux-pro-max](../.agents/skills/ui-ux-pro-max/SKILL.md) и [design-system](../.agents/skills/design-system/SKILL.md). По просьбе пользователя работа распределена между тремя субагентами: трафик; настройки/шаблоны; служебные экраны. Общая оболочка, токены, интеграция, визуальная проверка и развёртывание выполнены основным агентом.

## Основные изменения

- Общая панель gomate, четыре раздела, постоянный доступ к шаблонам/настройкам/теме. Состояние capture перенесено в нижнюю строку, которая не накрывает содержимое.
- Единая система CSS-токенов: тёмные/светлые поверхности, бирюзовый акцент, единые поля, кнопки, таблицы, диалоги и состояния фокуса. Убраны зависимость UI от удалённых шрифтов и старые глобальные стили фиксированных dropdown.
- Сервис, FIND-шаблон и избранное объединены в панель над сессиями; активные условия показаны снимаемыми метками. Сброс или изменение фильтра закрывает старую выбранную сессию. Выбор сессии из общей выборки больше не включает фильтр её сервиса.
- Над пакетами отдельные настройки содержимого, направления на текущей странице и Текст/HEX; активные ограничения можно снять по одному. Пакет содержит понятное направление/метаданные, компактное копирование и декодер.
- На телефоне список и содержимое расположены последовательно, фильтры можно свернуть; выбор новой сессии переводит к её содержимому. На низком экране список не перекрывает статус.
- Настройки сгруппированы по задачам; удаление выделено отдельно. Менеджер шаблонов показывает область/состояние правил, редактор объединяет условия и тестер, Docker-поиск показывает уже подключённые сервисы.
- Контейнеры имеют сводку/фильтры и мобильные карточки, логи — выделенную область просмотра. Аномалии получили структуру сводки/условий/результатов. В чате редактор закреплён в доступной высоте desktop, сообщения прокручиваются независимо.

## Проверки

- 11 unit-тестов: независимость фильтров/выбранной сессии, декодеры, Markdown и безопасность представления текста — прошли.
- Production frontend и Docker image собираются. Сохраняется предупреждение Vite о размере основного JS chunk; разделение bundle не входило в эту переработку.
- [Оболочка на Kali](ui-shell-redesign.json): четыре раздела × две темы × 1440/375 px, отсутствие горизонтального переполнения, низкий экран 1440×600, ошибки JS/API.
- [Трафик на Kali](ui-traffic-redesign.json): настоящие HTTP-данные через интерфейс eth1, параметры API при фильтрации, независимый сброс меток, общий scope, raw/decoded/направление/HEX, копирование, декодирование выделения, пауза и мобильные фильтры.
- [Настройки/редакторы на Kali](ui-settings-redesign.json): 1366/375 px, интерфейсы хоста, вкладки, поиск/пустые состояния, тест черновика шаблона, Docker-поиск и ручная форма. Конфигурация не изменялась; тест настроен блокировать запросы изменения, таких попыток в прогоне не было.
- [Изолированные UI-данные](ui-operations-redesign.json), **mocked=true**: 12 сочетаний страницы/темы/ширины для контейнеров, чата и аномалий. Проверены виртуализация 2000 строк логов/100 сообщений, фильтры и Markdown-preview; дополнительно редактор чата полностью виден на 1100×760. Эти результаты не являются нагрузочным тестом реального backend.
- [Контейнеры на реальном Kali](ui-container-live-redesign.json): подтверждённый перезапуск только временного fixture, настоящий Docker logs API, 19 DOM-строк при ограниченном снимке, stderr/поиск, просмотр строки и прекращение polling после перехода в чат.
- [Markdown-чат на Kali](ui-chat-formatting.json): два браузера, панель форматирования, предпросмотр, отправка/получение, копирование кода с отступами, повторное открытие истории, безопасный HTML и ширина 390 px — прошли.
- [Финальная визуальная регрессия](ui-final-redesign.json): цвета disabled-кнопок в обеих темах, редактор/отправка целиком в доступной высоте 1100×760, корректный переход к содержимому с клавиатуры без смены hash-маршрута.

Визуальная проверка выявила и устранила лишние разрывы строк CRLF в пакете, обрезание меню копирования и уход редактора чата ниже доступной области. Скриншоты сохраняются только как небольшие JPEG с качеством 30: [трафик](redesign-stream.jpg), [светлая тема](redesign-stream-light.jpg), [контейнеры](redesign-containers.jpg), [чат](redesign-chat.jpg), [аномалии](redesign-anomalies.jpg).

## Ограничения

Фильтр направления применяется к текущей странице пакетов; это явно написано в UI. В выборке сессий поддерживается один FIND-шаблон одновременно. Полнотекстовый поиск по всей истории и изменение backend-пайплайна не добавлялись. Виртуализация, лимиты данных и существующие API сохранены. Редизайн не подтверждает приёмку длительной соревновательной нагрузки.

## Развёртывание и данные

Обновлены app и discovery на http://192.168.56.103:65000. Предыдущий образ сохранён на стенде под тегом `gomate-app:before-ui-redesign`. [Манифест финальной сборки и диагностика](ui-redesign-build.json) содержит image IDs, совпадение слоёв и хеши frontend-файлов.

После функциональных проверок исправлен только цвет disabled-кнопок, который перебивался специфичными правилами Bootstrap; финальный smoke проверяет эти цвета в обеих темах. [Очистка тестовых данных](ui-redesign-cleanup.json): два временных контейнера удалены с проверкой fixture-метки, удалены только два сообщения с уникальным префиксом запуска теста Markdown. Пользовательские сообщения и конфигурация сохранены. Две синтетические HTTP-сессии остаются до штатной retention.
