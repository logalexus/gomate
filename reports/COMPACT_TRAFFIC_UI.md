# Компактное представление трафика

Изменения от 2026-11-14 после первого редизайна.

- Панель фильтров заменена рядом переключаемых меток с переносами. Несколько шаблонов объединяются через AND; сервис и избранное независимы. Выбор шаблонов сохраняется в ссылке, старые ссылки поддерживаются.
- Кнопки меток имеют `aria-pressed`, управляются клавиатурой, выбранные отмечены галочкой. Для большого числа шаблонов область меток прокручивается с ограничением высоты, сохраняя место сессиям.
- Убраны надзаголовки и повторяющиеся описания, уменьшены общая навигация, отступы карточек, панели представления и пагинация.
- В списке сессий показывается первый распознанный путь HTTP/HTTP2/gRPC. Он сохраняется при записи чанка вместе с сессией, без чтения пакетов при каждом обновлении списка. Поздние запросы не заменяют первый путь; очистка payload его не удаляет.
- Миграция v8 добавляет nullable-поля без переписывания истории. Старые сессии автоматически не пересчитываются. Поле пути ограничено 2048 байтами; сокращение отмечается многоточием. TCP без распознанного пути остаётся без подписи.

## Backend и стенд

Новые интеграционные тесты с `-race -count=1` пройдены:

- `TestStreamMultiPatternAPIAndCursor`: AND нескольких ID, legacy `pattern.id`, сервис, избранное, cursor, ограничения и некорректные ID.
- `TestFirstRequestMetadataIsStableAndSurvivesPayloadCleanup`: первый входящий HTTP/H2/gRPC-путь, игнорирование ответов и поздних запросов, повторы записи, Unicode/ограничение длины и сохранение после очистки payload.

Unit/compiler-проверки model/storage/analyze/api пройдены. Полный race-прогон **не зелёный**: два запуска (включая последовательные пакеты `-p=1`) падают только в существующем `TestAnonymousChatPersistenceIdempotencyPaginationAndBounds`, `collaboration_test.go:89`. Семь последовательных DB-запросов не укладываются в интервал пополнения лимитера: ожидается 429, получено 201. Реализация и тест чата в этой задаче не менялись.

Образ установлен на `http://192.168.56.103:65000`; app и discovery используют одинаковый образ. Readiness true, захват работает на eth1. Идентификаторы образов и rollback: compact-traffic-deployment.json (`compact-traffic-deployment.json`, локальный артефакт).

`node tests/browser/ui-traffic-redesign.cjs` на обновлённой Kali — **PASS**, без ошибок браузера: реальный HTTP-запрос через интерфейс eth1, путь в списке сессий, несколько шаблонов, сервис/избранное, сброс, представление/направление, HEX/копирование, Base64-декодер, пауза и переход к сессии на экране 375 px. Отчёт: ui-compact-traffic-live.json (`ui-compact-traffic-live.json`, локальный артефакт), тестовая сессия #56356. Избранное этой сессии после проверки снято.

Проверка адаптирована к постоянному входящему трафику: собственная тестовая сессия временно закрепляется в избранном, чтобы не уйти с первой страницы до проверки. Выявленный дефект прокрутки короткой сессии на телефоне исправлен минимальной высотой области содержимого по высоте рабочей области; локальная и реальная браузерные проверки перехода проходят.
