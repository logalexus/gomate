# Проверка мини-шутера

Дата: 2026-11-15. Вход: **Чат → Арена → Войти на арену**.

## Результат

Добавлена общая полноценная 3D-арена на WebGL до 16 игроков с именами из чата, укрытиями, серверными попаданиями, счётом и автоматическим возрождением. Игра загружается по кнопке, не обращается к БД или очередям захвата. Закрытие сохраняет черновик чата. Описание управления и ограничений: [ARENA.md](../docs/ARENA.md).

## Выполненные проверки

- `.tools/go/bin/go test -race ./internal/arena ./internal/api` — PASS. Проверены движение, стены, ближайшая цель, частота выстрелов, защита и возрождение, остановка устаревшего ввода, 16 WebSocket-подключений, лимит комнаты, повторный вход, остановка пустой комнаты, Origin, неверный ввод, флуд, Basic Auth и идентичность имени чата. Отдельно проверены промахи выше головы и в пол, а также допустимые границы вертикального прицела.
- `npm --prefix web run build` — PASS. Арена выделена в отдельный динамический chunk. Существующее предупреждение о размере основного bundle остаётся.
- `node tests/browser/arena.cjs` — PASS. Проверены настоящий WebGL-контекст и включённая проверка глубины, репликация вертикального угла. Два Chromium-клиента подключены к настоящему Go WebSocket-серверу. Движение видно сопернику; три попадания дают фраг, игрок возрождается; счёт синхронизируется. Проверены пауза, выход, сохранение черновика, мобильное окно игры и размещение композера/кнопки в пяти размерах окна и двух темах. Подменены только API вне игры. Ошибок JavaScript нет: JSON (`arena-browser.json`, локальный артефакт), небольшой JPEG (`arena-desktop.jpg`, локальный артефакт).
- `node tests/browser/arena-live.cjs` — PASS на `192.168.56.103:65000`: два браузера вошли с именами чата, проверены WebGL и глубина, сервер принял движение и вертикальный прицел, после выхода захват работает и readiness отвечает успешно. Сообщения в чат тест не публиковал: JSON (`arena-live.json`, локальный артефакт).

Дополнительно запускался общий `ui-operations-redesign.cjs`: остановился на устаревшем селекторе `.gm-page-title` страницы «Аномалии», где сейчас обычный `<h1>`. Это не успешная общая регрессия интерфейса. Проверки изменённого чата выполнены отдельно в `arena.cjs`; код аномалий в рамках арены не менялся.

## Производительность

`BenchmarkFullRoomTick`, Intel Core i7-12700F, 16 симулируемых игроков с движением и огнём: **21 356 нс/op, 3675 B/op, 6 allocs/op**. Бенчмарк включает шаг симуляции и сериализацию снимка через шаг; не включает сетевую передачу, рендер браузера или нагрузку захвата трафика. Это не результат нагрузочного теста всего анализатора.

Сервер ограничен 20 шагами/с, 10 снимками/с и 16 игроками; у клиента очередь только для последнего снимка. В пустой комнате таймер останавливается. Полный длительный тест захвата одновременно с 16 активными браузерами в этой проверке не проводился.
