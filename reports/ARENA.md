# Проверка мини-шутера

Дата: 2026-11-14. Вход: **Чат → Арена → Войти на арену**.

## Результат

Добавлена общая ретро-3D арена до 16 игроков с именами из чата, укрытиями, серверными попаданиями, счётом и автоматическим возрождением. Игра загружается по кнопке, не обращается к БД или очередям захвата. Закрытие сохраняет черновик чата. Описание управления и ограничений: [ARENA.md](../docs/ARENA.md).

## Выполненные проверки

- `.tools/go/bin/go test -race ./internal/arena ./internal/api` — PASS. Проверены движение, стены, ближайшая цель, частота выстрелов, защита и возрождение, остановка устаревшего ввода, 16 WebSocket-подключений, лимит комнаты, повторный вход, остановка пустой комнаты, Origin, неверный ввод, флуд, Basic Auth и идентичность имени чата.
- `npm --prefix web run build` — PASS. Арена выделена в отдельный динамический chunk. Существующее предупреждение о размере основного bundle остаётся.
- `node tests/browser/arena.cjs` — PASS. Два Chromium-клиента подключены к настоящему Go WebSocket-серверу. Движение видно сопернику; три попадания дают фраг, игрок возрождается; счёт синхронизируется. Проверены пауза, выход, сохранение черновика, мобильное окно игры и размещение композера/кнопки в пяти размерах окна и двух темах. Подменены только API вне игры. Ошибок JavaScript нет: [JSON](arena-browser.json), [небольшой JPEG](arena-desktop.jpg).
- `node tests/browser/arena-live.cjs` — PASS на `192.168.56.103:65000`: два браузера вошли с именами чата, сервер принял движение, после выхода захват работает и readiness отвечает успешно. Сообщения в чат тест не публиковал: [JSON](arena-live.json).

Дополнительно запускался общий `ui-operations-redesign.cjs`: остановился на устаревшем селекторе `.gm-page-title` страницы «Аномалии», где сейчас обычный `<h1>`. Это не успешная общая регрессия интерфейса. Проверки изменённого чата выполнены отдельно в `arena.cjs`; код аномалий в рамках арены не менялся.

## Производительность

`BenchmarkFullRoomTick`, Intel Core i7-12700F, 16 симулируемых игроков с движением и огнём: **22 068 нс/op, 3506 B/op, 6 allocs/op**. Бенчмарк включает шаг симуляции и сериализацию снимка через шаг; не включает сетевую передачу, рендер браузера или нагрузку захвата трафика. Это не результат нагрузочного теста всего анализатора.

Сервер ограничен 20 шагами/с, 10 снимками/с и 16 игроками; у клиента очередь только для последнего снимка. В пустой комнате таймер останавливается. Полный длительный тест захвата одновременно с 16 активными браузерами в этой проверке не проводился.
