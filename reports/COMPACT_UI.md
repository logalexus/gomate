# Компактный интерфейс и добавление Docker-сервисов

Обновлено 2026-11-15; проверено на `192.168.56.103:65000`.

## Добавление сервиса

В «Добавить сервис → Из Docker» кнопка «Добавить» открывает вкладку
«Параметры» с заполненными именем и опубликованным портом. Можно изменить
имя, включить HTTP/HTTP2/gRPC, декодирование URL и WebSocket. Сервис создаётся
только после «Сохранить»; отмена ничего не записывает. Ошибка сохранения
оставляет введённые значения для исправления и повторной попытки.

Порт подтверждается Docker discovery на сервере. Для изменения порта есть
«Редактировать порт вручную», переводящая форму в обычное ручное добавление.
Существующий сервис на этом порту не перезаписывается. Старый API-запрос
`POST /api/v2/docker-services` с одним `id` остаётся совместимым; новый
необязательный объект `service` передаёт имя и настройки разбора.

## Интерфейс

- Общая навигация, кнопки, формы, таблицы и модальные окна используют меньшие
  отступы; верхняя панель на настольном экране занимает 48 px.
- Настройки, редактор и менеджер шаблонов, поиск по истории уплотнены.
  На широком экране настройки хранения и ручная очистка расположены рядом.
  Таблица шаблонов на узком экране перестраивается без горизонтальной прокрутки.
- Действия сессии помещены в заголовок. Уплотнены чат, декодер, окно скриптов
  и отправки сессии в чат. Размер текста сообщений и содержимого трафика сохранён.
- Светлая и тёмная темы поддерживаются; на сенсорных устройствах общие
  элементы управления имеют минимальную высоту 36 px.

## Проверки

Сборки Go и frontend прошли. Go-тесты `./internal/api ./internal/discovery`
и интеграционный `TestDockerServiceEditableSettings` с отдельной PostgreSQL
проверяют настройки, авторитетный Docker-порт, валидацию, устаревший кандидат,
дубликат без перезаписи и совместимость старого запроса.

Браузерные проверки прошли: `service-docker-form`, `service-delete`,
`compact-forms`, `session-share`, `session-export`, `request-workbench`,
`ui-compact-traffic`, `anomaly-groups`, `containers-compact`.
Сохранение и ошибки Docker-формы проверены с подменённым API, в том числе
на собранном интерфейсе инстанса. Реальная запись проверена интеграционным тестом.

`compact-app-live` проверил настоящий инстанс на ширинах 1366/800/375 px
в обеих темах: Docker-черновик, настройки, шаблоны, чат; без переполнений
и ошибок JavaScript. Записывающих запросов не было, сервисы не изменились,
захват продолжал работать в течение проверки. JSON-отчёты и скриншоты — рядом.

## Развёртывание

Обновлён только контейнер приложения, остальные контейнеры не перезапускались.
Образ: `gomate-app:compact-app-20261115t003938z`.
Предыдущий образ: `gomate-app:before-compact-app-20261115t003938z`.
Состояния контейнеров сохранены в `compact-app-deployment.json`.
