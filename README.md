# Gomate

Инструмент на Go для анализа сетевого трафика и командной работы на CTF Attack/Defense. Основан на Packmate.

## Возможности

- Захват TCP/UDP в реальном времени и чтение PCAP.
- Разбор HTTP/1.1, HTTP/2, gRPC и WebSocket; TLS не расшифровывается.
- Поиск по тексту и regex, шаблоны FIND/IGNORE, поиск по истории и избранное.
- Группировка похожих сессий и обнаружение аномального трафика.
- Декодирование JWT, Base64, URL и HEX; запуск скриптов для повторения запросов.
- Управление Docker-контейнерами, просмотр логов и общий чат.
- Ферма флагов: сдача на борду, история, статистика и Python-клиент для запуска сплоитов.

## Быстрый запуск

Нужны Linux, Git, Docker Engine с Compose v2 и `openssl`.

```sh
git clone git@github.com:logalexus/gomate.git
cd gomate
./scripts/deploy.sh
```

Скрипт создаст `.env` со случайными паролями, соберёт образы и запустит сервисы. Существующий `.env` сохраняется.

Откройте **http://<IP-сервера>:65000**. По умолчанию Gomate слушает все IPv4-интерфейсы (`0.0.0.0:65000`). Логин — **packmate**, пароль можно посмотреть командой:

```sh
sed -n 's/^WEB_PASSWORD=//p' .env
```

В настройках выберите сетевой интерфейс и включите **LIVE**, затем добавьте сервис через **«+ Сервис»** — из Docker или вручную.

Все HTTP-маршруты и WebSocket защищены Basic Auth. Для доступа через интернет используйте HTTPS или VPN: Basic Auth сам по себе не шифрует пароль.

Данные и настройки сохраняются в Docker volume. Обновление и остановка:

```sh
git pull --ff-only && ./scripts/deploy.sh  # обновить
docker compose down                      # остановить, сохранив данные
```
