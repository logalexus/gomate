# Контейнеры, логи и общий чат

## Контейнеры

Верхняя вкладка **Контейнеры → Управление** показывает все контейнеры Docker: имя, образ, ID, состояние, текстовый статус (включая health, если он настроен) и порты. Есть поиск, фильтр состояния и страницы по 25 строк. Список обновляется каждые 5 секунд, пока вкладка браузера видима.

Доступные действия зависят от состояния: **Запустить**, **Остановить**, **Перезапустить**, **Пауза**, **Продолжить**. Для остановки, перезапуска и паузы UI запрашивает подтверждение с именем контейнера. У stop/restart Docker получает 5 секунд на штатное завершение. Если запрос завершился по тайм-ауту, сначала обновите статус: действие могло уже начаться в Docker.

Контейнеры самого gomate помечены и доступны только для просмотра. Это обеспечивается также шлюзом, а не только скрытием кнопок. Для своего Compose-проекта используйте метку `gomate.internal=true` на app, db и discovery, как в поставляемой конфигурации. Стандартные имена Compose-проектов gomate/gomate-lab также распознаются для совместимости с прежней версией.

## Логи

Нажмите **Логи** в строке контейнера или откройте соответствующую вкладку и выберите контейнер. Настройки:

- Период: 5 минут, час, сутки или доступная история Docker.
- Последние 100, 500, 1000 или 2000 строк.
- Поиск текста без учёта регистра, фильтр stdout/stderr.
- LIVE с обновлением каждые 2 секунды, отдельный переключатель прокрутки в конец.
- Полный текст строки по нажатию, копирование из диалога.

Поиск работает **только внутри загруженного фрагмента**, не сканирует всю историю Docker. У контейнеров с TTY stdout/stderr объединены; фильтр потока отключается. Если logging driver не предоставляет Docker API чтения логов, интерфейс покажет ошибку. Вывод с HTML отображается как текст, управляющие ANSI-последовательности удаляются.

Просмотр использует ограниченные снимки, а не бесконечно растущий буфер: максимум 2000 строк / 512 KiB текста на снимок, строка сокращается после 4096 байтов. Шлюз читает максимум 2 MiB исходного потока за запрос; при достижении лимита вывод помечается сокращённым и может не доходить до самых свежих строк. Уменьшите период или число строк. При интенсивном выводе промежуточные строки между снимками могут быть пропущены; gomate не заменяет хранилище логов.

В DOM отрисовываются только видимые строки и небольшой запас. Поиск отложен на 200 мс. Запросы логов не накладываются друг на друга; скрытая вкладка прекращает polling, уход со страницы прерывает запрос. Шлюз одновременно обслуживает не более двух чтений логов и двух действий управления. Эти операции не используют очередь capture или транзакции записи трафика.

## Чат

Вкладка **Чат** общая для всех участников с доступом к этому экземпляру gomate. Отдельных пользователей, регистрации и профилей нет. Сервер выдаёт имя вида `Аноним-1234abcd` и подписанную HttpOnly cookie. Имя сохраняется в браузере на 7 дней и при перезапуске приложения; другой браузер получает другое имя. Общая HTTP-аутентификация gomate остаётся: анонимность означает отсутствие персональных аккаунтов в чате.

Сообщения поддерживают Markdown: **жирный**, *курсив*, зачёркнутый текст, код внутри строки, блоки кода, списки, цитаты, ссылки и таблицы. Меню **+** слева от поля ввода форматирует выделенный текст; пункт **Предпросмотр** показывает результат до отправки. Чат занимает всю рабочую область: компактная шапка, аватары и время рядом с именем, прокручиваемая лента и закреплённый снизу ввод. Подсказки и счётчик не занимают место у поля; анонимное имя и сведения о канале доступны по кнопке **О канале** в шапке. Исходный Markdown сохраняется в БД; старые сообщения также отображаются с форматированием.

Для блока кода поставьте три обратные кавычки на отдельных строках. После открывающих можно написать язык — он будет показан над блоком:

````text
```go
if response.StatusCode == 200 {
    fmt.Println("OK")
}
```
````

У блока есть кнопка **Копировать**: она копирует код с отступами, без Markdown-ограждений. Длинный код прокручивается внутри блока. Название языка служит подписью; подсветки синтаксиса пока нет.

**Enter** отправляет сообщение, **Shift+Enter** добавляет строку. Внутри блока кода **Enter** добавляет строку; **Ctrl+Enter** / **⌘+Enter** в поле ввода отправляет сообщение. Максимум — 2000 символов вместе с разметкой. Если отправка не удалась, текст остаётся в поле; повторная отправка того же сообщения использует прежний ключ и не создаёт дубль.

HTML отображается как текст. Внешние картинки не загружаются; ссылки разрешены только для HTTP(S) и mailto, открываются в отдельной вкладке. Рендерер использует `markdown-it` с отключённым HTML, согласно его [рекомендациям по безопасности](https://github.com/markdown-it/markdown-it/blob/master/docs/safety.md).

Сообщения хранятся в PostgreSQL; видимая история ограничена 7 днями и 10 000 сообщениями. Старые записи удаляются при очередной отправке. Клиент читает страницы по 100 сообщений, держит максимум 500, виртуализирует список и обновляет его каждые 2 секунды. Кнопка **История** в шапке загружает предыдущую страницу. При просмотре старой истории LIVE приостанавливается; кнопка **К новым сообщениям** возвращает актуальную страницу. В скрытой вкладке polling отключён. На отправку действуют ограниченные burst/rate бюджеты на браузер и на весь процесс, чтобы чат не вытеснял запись трафика.

## Развёртывание

Используется существующий контейнер `discovery` и секрет `DOCKER_DISCOVERY_TOKEN`; дополнительные порты наружу не открываются. Основной app не получает Docker socket. Шлюз на localhost:65001 предоставляет только фиксированные маршруты, проверяет полный ID контейнера и разрешённое действие. Произвольный Docker API, команды в контейнере, создание/удаление контейнеров или томов не доступны через этот UI.

Обновите образ **app и discovery вместе**. Миграция БД версии 6 добавляет отдельную таблицу чата, существующий трафик и настройки сохраняются. Доступ к управлению контейнерами получают все, у кого есть общий доступ к gomate; отдельных ролей в текущей модели нет.

Форматы логов и lifecycle endpoints сверены с [официальным Docker Engine API](https://docs.docker.com/reference/api/engine/version/v1.45/). Проверки реализации описаны в [отчёте](../reports/CONTAINERS_CHAT.md).
