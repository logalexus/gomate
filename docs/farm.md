# Ферма GoMate

Ферма встроена в GoMate на Go. Очередь и конфигурация находятся в существующей PostgreSQL; дополнительные контейнеры фермы не нужны. При первом запуске сдача выключена.

## Настройка

Откройте **Настройки → Ферма**:

- **RuCTF HTTP** — протокол по умолчанию. Укажите полный URL приёмника борды (IP, порт и path) и **X-Team-Token**. Используется PUT с JSON-массивом флагов.
- **ForcAD HTTP** — такой же HTTP transport актуального ForcAD. TCP-вариант старых сборок не реализован.
- **Volga API v1** — базовый URL вида `https://board/api/flag/v1`; отправка POST `/submit` с флагом в text/plain. `X-Team-Token` этот протокол не использует. Предварительная проверка подписи и `/info` не выполняется, вердикт берётся у борды.

Токен после сохранения возвращается только признаком наличия. Пустое поле сохраняет прежний токен; отдельный checkbox удаляет его. Для доступа UI и клиента применяется существующая Basic Auth GoMate.

Шаблон `10.60.{n}.3` с диапазоном 1–50 генерирует команды. Можно добавить строки `Имя = IP` и исключить IP своей команды и других участников. Предпросмотр показывает итоговый список. Изменения клиент получает перед следующим раундом. Уже запущенные процессы завершают текущий раунд.

Регулярное выражение проверяется сервером (Go RE2, без backtracking). Для Python-клиента используйте общий с Python синтаксис, например `[A-Z0-9]{31}=`. Ограничения: до 1024 сгенерированных целей, до 2048 дополнительных целей, 1–64 одновременных запусков на клиенте. Дополнительные клиенты имеют собственные лимиты параллельности.

## Работа

Вкладка **Ферма** содержит ручную сдачу текста с флагами, таблицу, поиск по флагу/ответу, фильтры по команде, сплоиту, времени и статусу, статистику команд. История постраничная, по 50 строк; автообновление раз в 3 секунды, его можно приостановить.

Статусы: `QUEUED`, `SUBMITTING`, `ACCEPTED`, `REJECTED`, `SKIPPED`. Уникальность флага обеспечивает PostgreSQL. Сетевая ошибка, неизвестный ответ и временные ошибки повторяются с задержкой до 60 секунд. Просроченные флаги пропускаются, терминальная история очищается порциями. Зависшая отправка восстанавливается после истечения lease; его срок рассчитан на таймаут полного batch. Борда должна поддерживать повторную сдачу одного флага: exactly-once через внешнюю сеть не гарантируется. Очередь ограничена 100000 активных флагов, ручная сдача — 1000 флагов / 1 MiB за запрос.

Рекомендуется настроить срок жизни по правилам игры и хранение истории на 1–2 дня. Пауза сдачи сохраняет очередь, но срок жизни продолжает идти.

## Клиент и шаблон

В разделе **Сплоит и клиент** доступны редактируемый Python-шаблон HTTP/TCP с подсветкой и скачивание `gomate_client.py`. Шаблон — стартовая заготовка для собственного сплоита. Он получает IP через `sys.argv[1]` и печатает весь ответ через `print(data, flush=True)`. Клиент извлекает флаги по формату из настроек; регулярка в сплоите не нужна. Команда запуска в UI автоматически содержит текущий логин и пароль GoMate в аргументах `--user` и `--password` и доступна для копирования.

```sh
python3 gomate_client.py --server http://gomate:65000 --user='packmate' --password='your-password' --name service-one -- python3 sploit.py
```

HTTP-шаблон использует `requests` (`python3 -m pip install requests`). Клиент требует только Python 3.9+ и стандартную библиотеку. Аргументы `--user` и `--password` имеют приоритет над прежними переменными окружения. Каждую команду запускает отдельным процессом, ограничивает время и объём читаемого stdout 1 MiB. Флаги сохраняет в локальный SQLite outbox; при недоступности фермы сохраняет до 100000 записей за последние сутки и повторяет сдачу. Для разных независимых экземпляров задайте разные `--spool`. `--once` выполняет один раунд. Этот клиент запускается на машине автора сплоита; вкладка не является сервером распределённого исполнения сплоитов.

## Происхождение

Потоки интерфейса, модель статусов и совместимость RuCTF/Volga адаптированы из [S4DFarm](https://github.com/C4T-BuT-S4D/S4DFarm); клиентский сценарий ориентирован на [DestructiveFarm](https://github.com/DestructiveVoice/DestructiveFarm). ## Проверки

```sh
go test ./...
FARM_TEST_DATABASE_URL=postgres://postgres:farmtest@127.0.0.1:65433/gomate_farm_test go test -race ./internal/farm -count=1
python3 tests/farm_client_test.py
node tests/browser/farm.cjs
npm --prefix web run build
```

Тестовая база должна быть отдельной и называться `gomate_farm_test`: тест очищает только таблицы фермы в этой базе. Проверяются исключения IP, формат regex, токен и протоколы, переставленные ответы борды, дубли, сохранение токена и revision-конфликты, пауза, сдача, восстановление lease и expiry; Python-клиент проверяется на локальном HTTP-моке.
