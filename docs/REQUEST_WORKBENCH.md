# Редактор и запуск запросов

В карточке входящего блока откройте **Копировать → Python requests… / curl… / pwntools…**. Откроется редактор готового скрипта. Можно изменить код, скопировать его целиком или нажать **Запустить**. Адрес соединения берётся из сохранённой сессии, включая порт; его можно заменить перед генерацией.

Окно занимает почти весь экран: слева — увеличенный редактор, справа — вывод выполнения с отдельной прокруткой. На телефоне панели располагаются друг под другом. Редактор подсвечивает Python и Bash по выбранному языку выполнения, показывает номера строк, поддерживает автоотступы и отмену правок (Ctrl/Cmd+Z). Tab переводит фокус к следующему элементу; Ctrl/Cmd+[ и ] меняют отступ. Подсветка следует светлой и тёмной теме.

Настройки сверху относятся к генератору. Если код уже отредактирован вручную, изменение адреса/формата не затирает его: кнопка **Сгенерировать заново** явно заменяет текст. **Запустить** отправляет именно текущий текст редактора и выбранный язык выполнения — Python 3 или Bash.

HTTP `Host`, cookies и прочие заголовки сохраняются из запроса. Изменение адреса подключения само по себе не меняет `Host`. Когда в raw-блоке несколько полных HTTP-запросов, можно выбрать нужный. Для неполного HTTP доступны имеющиеся raw-байты через pwntools; восстановленное HTTP-представление может отличаться от исходных байтов. Ограничения конкретного экспорта перечислены в раскрываемой подсказке. HTTP/2/gRPC не преобразуются автоматически в HTTP/1.

## Выполнение

Скрипт действительно исполняется в Python/Bash на сервере gomate, в новом контейнере с requests, pwntools, curl и binutils. Это **не эмуляция HTTP-запроса**. Сеть контейнера совпадает с сетью хоста gomate: доступны CTF-сервисы по их адресам и опубликованным портам.

stdout/stderr обновляются во время запуска. Отображаются длительность, код возврата, ошибки и таймаут. Кнопка **Остановить** и закрытие окна останавливают текущий запуск. Повторный запуск создаёт новое окружение; временные файлы прошлого запуска не сохраняются.

Текущая версия выполняет скрипты **без интерактивного stdin/PTY**: `input()`, `pdb` и `io.interactive()` не предоставляют диалоговый терминал. Для тестирования можно изменить скрипт и повторить запуск; сгенерированный pwntools-код читает ответ с ограничением времени.

Лимиты:

- 2 одновременных запуска; 30 секунд по умолчанию, максимум 120 секунд.
- Код до 256 KiB; stdout + stderr до 512 KiB. Браузер показывает последние 64 Ki символов каждого сохранённого потока.
- На контейнер: 0.5 CPU, 512 MiB RAM, 64 процесса, временный `/tmp` 64 MiB.
- Непривилегированный пользователь, read-only root, без Docker socket, файлов хоста и секретов приложения. Сеть хоста доступна намеренно.
- Контейнер удаляется после завершения/остановки; при рестарте шлюза очищаются оставшиеся контейнеры только с меткой этого runner.
- До 32 результатов хранятся в памяти шлюза 15 минут, без сохранения скриптов в БД.

## Установка

Перед первым запуском соберите образ:

```sh
docker compose --profile tools build runner-image
docker compose up -d --build app discovery
```

`RUNNER_IMAGE` в discovery указывает фиксированный образ `gomate-runner:latest`. Пользовательский код не может выбрать другой образ, mounts или Docker-параметры. Если образ недоступен, редактирование и копирование работают, запуск отключён.

На Kali образ собирается локально из `deploy/runner/Dockerfile` и загружается через `docker save | ssh ... docker load`; Compose находится в `deploy/kali/compose.yaml`.

API: `GET /api/v2/runner`, `POST /api/v2/runner/jobs` (`language`, `code`, `timeoutSeconds`), `GET /api/v2/runner/jobs/:id`, `DELETE /api/v2/runner/jobs/:id`. Используется существующая аутентификация gomate. Адрес сессии для генератора: `GET /api/stream/:id`.

При реализации проверены официальные документы [curl](https://curl.se/docs/manpage.html), [requests](https://requests.readthedocs.io/en/latest/user/advanced/) и [pwntools](https://docs.pwntools.com/en/stable/tubes/sockets.html).
